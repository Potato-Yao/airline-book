# Airline-book

[project's github](https://github.com/Potato-Yao/airline-book)

Airline book system, as the final project of OOP course.

Works on my fedora 42 laptop.

## build

This project is built by cmake, so run this command to build it with release level optimization:

```bash
cmake -B build-release -DCMAKE_BUILD_TYPE=Release && cmake --build build-release
```

There's a python script for generating plane data. Simply running it by

```bash
python csv_generator.py
```

It will generate a csv file with 100000 rows of data, named `__airline_data__.csv`. Copy it to the same directory as the executable to make the program runs under the data.
